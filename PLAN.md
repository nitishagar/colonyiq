## 1. Test runner choice

- **vitest** everywhere for TS: unit (parser, pipeline math), Worker contract tests
  (`@cloudflare/vitest-pool-workers` or plain `app.request()` Hono tests — prefer plain
  Hono `app.request()` for offline speed, workers pool only if needed for bindings),
  eval-metrics unit tests, checklist grep tests.
- **No pytest**: eval tables generated by a small `eval/tables.mjs` node script (or
  `eval/tables.py` stdlib-only if preferred) from eval JSON; vitest asserts the JSON,
  file-existence checks assert the tables.
- Commands: `pnpm -r test` (offline suite, must pass with no network/keys),
  `pnpm -r test:live` (gated by `COLONYIQ_LIVE=1` + secrets; skipped otherwise).
- Package manager: **pnpm workspaces** (matches bharatdcim layout); fallback npm
  workspaces if pnpm missing.

## 3. Offline-vs-live split

- **OFFLINE** (`pnpm -r test`, CI-safe, no keys/network): all vitest unit tests
  (parser/pipeline/metrics/splits/CFU), Hono `app.request()` contract tests with mocked
  upstream fetch (subrequest count, CORS cfg, model-pinned grep, killswitch env gate,
  rate-limit unit), README/attribution/license grep tests, file-existence tests
  (demo-mode JSON, backup video exists), `vite build`, `wrangler deploy --dry-run` /
  typecheck.
- **LIVE** (`COLONYIQ_LIVE=1 pnpm -r test:live`, needs `META_API_KEY` server-side +
  deployed Worker + owner-authenticated wrangler): data-URI probe, SAM smoke-5,
  key-from-India, deployed hello/e2e, CPU/subrequest tail checks, burst 429 probes,
  Origin probes, tampered-model probe, bundle no-key check, eval driver via Worker,
  latency timing, paywall absence. Manual-only (no automatable assertion): spend-cap
  console check + screenshot, video playability watch, phone-friendly e2e eyeball.

## 5. AGAR data rules (prior3)

- Source `AGAR_demo/AGAR_representative`: 40 jpg + 40 json, 10/bin
  (bright/dark/vague/lower-res). Label rows `{class,height,id,width,x,y}` int px,
  1-based id. Totals: 1886 labels; bright 863, dark 319, vague 317, lower-res 387.
- Quirks (hardcode in `splits.test.ts` + metrics): bright/734 `colonies_number`=54
  vs 78 labels (24 Contamination excluded) → report both, use 78 for IoU;
  bright/1399 `colonies_number`=-1, labels=[] → TNTC reading ONLY after AGAR docs
  check; bright/971 filename vs `sample_id`=972 mismatch → key by filename, note it.
- Dev20 = 10 lower-res + 10 bright (tune freely); test20 = dark+vague (run once Nov2).
